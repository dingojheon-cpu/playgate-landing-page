# PlayGate 랜딩페이지

플레이게이트(PlayGate)의 무인매장 통합 AS 및 토탈 케어 서비스 소개 페이지입니다.

- 공개 페이지: https://dingojheon-cpu.github.io/playgate-landing-page/
- GitHub 저장소: https://github.com/dingojheon-cpu/playgate-landing-page

## 파일 구성

- `index.html`: 페이지의 문구, 디자인, 상담 신청 폼이 포함된 원본 파일

## 수정 및 게시

`index.html`을 편집하면 페이지 문구, 케어 플랜 금액, 디자인을 수정할 수 있습니다. 수정한 파일을 GitHub 저장소의 `main` 브랜치 루트에 반영하면 GitHub Pages가 자동으로 다시 게시합니다.

별도 빌드 과정은 필요하지 않습니다. 로컬에서는 `index.html`을 브라우저로 열어 확인할 수 있습니다.

## 상담 신청 폼

이름, 연락처, 매장명, 매장위치, 매장평수, 문의내용 및 증상설명, 개인정보 동의 항목이 구성되어 있습니다. 현재는 브라우저에서 필수 항목을 확인하지만, **신청 내용이 전송되거나 저장되지는 않습니다.** 실제 상담 접수를 받으려면 별도의 수신 서비스 또는 서버 연동이 필요합니다.

## 이미지

메인 이미지는 외부 Unsplash 주소를 참조합니다. 이미지 제공 상태나 네트워크 연결에 따라 표시되지 않을 수 있습니다.
