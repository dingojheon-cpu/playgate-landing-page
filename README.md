# PLAYGATEUFO 랜딩페이지

25년 현장 경험과 전문 AS 시스템을 중심으로 구성한 뽑기방 창업 랜딩페이지입니다.

## 주요 구성

- 네온 컬러 믹스와 3D UFO 모션을 적용한 메인 비주얼
- 두 가지 메인 타이틀 자동 전환
- 25년 노하우, 맞춤 설계, 설치·세팅, 전문 AS 경쟁력 소개
- 상담부터 사후관리까지 6단계 창업 프로세스
- 실제 매장 사진 16장의 4×4 갤러리 및 더보기 기능
- 반응형 모바일 내비게이션과 이메일 창업문의 연결
